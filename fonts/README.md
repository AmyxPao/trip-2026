# 字型

- `barlow-condensed-600.woff2`、`barlow-condensed-700.woff2`：Barlow Condensed（Jeremy Tribby），SIL Open Font License 1.1，取自 Google Fonts，只含拉丁字集。用於日期、時間、金額等數字。
- `yuji-syuku-stamps.woff2`：Yuji Syuku（Kinuta Font Factory），SIL Open Font License 1.1，取自 Google Fonts，只含印章用到的字：確 次 電 衝 済 実 估 我 伴 未。要在印章上用新字，需重新下載包含該字的子集。
